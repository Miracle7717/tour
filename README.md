# Конные и активные туры

Backend на Django REST Framework для сервиса бронирования конных, пеших, мото- и других активных туров. Интерактивная документация API доступна в Swagger UI.

## Запуск локально

Требуется Python 3.10+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Для разработки используются SQLite и тестовый `SECRET_KEY`. Перед публикацией задайте `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0` и `DJANGO_ALLOWED_HOSTS` через окружение.

## Документация API

- Swagger UI: `http://127.0.0.1:8000/api/docs/`
- OpenAPI-схема: `http://127.0.0.1:8000/api/schema/`
- Файл документации OpenAPI: [`docs/openapi.yml`](./docs/openapi.yml)
- Документация тестирования запросов на запись: [`docs/TESTING.md`](./docs/TESTING.md)
- Админ-панель: `http://127.0.0.1:8000/admin/`

Файл схемы создан из Django API командой `python manage.py spectacular --validate --file .\docs\openapi.yml`. После изменения API повторите команду, чтобы обновить документацию.

Категории и туры создаются/изменяются только администратором. Для регистрации доступен открытый endpoint; бронирования и отзывы требуют входа (Basic или Session authentication). Статус бронирования меняется сотрудником через админ-панель.

## Основные связи и бизнес-правила

- `User` — `UserProfile`: один к одному; профиль создаётся при регистрации.
- `User` — `Booking` и `Tour` — `Booking`: один ко многим.
- `Tour` — `Category`: многие ко многим; один тур может относиться к нескольким категориям, например «конный» и «пеший».
- `Booking` — `Review`: один ко многим; участник может оставить несколько отзывов о завершённом бронировании.
- Активное бронирование уникально для участника и точного времени начала вне зависимости от выбранного тура. Отменённое бронирование не блокирует повторную запись на это время. Ограничение также задано на уровне базы данных.
- Оставить отзыв можно только на своё завершённое бронирование; оценка — от 1 до 5.

## Endpoints

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/api/auth/register/` | Регистрация участника с профилем |
| `GET` | `/api/categories/` | Список категорий |
| `GET`, `POST`, `PUT`, `PATCH`, `DELETE` | `/api/categories/`, `/api/categories/{id}/` | Управление категориями (администратор) |
| `GET` | `/api/tours/`, `/api/tours/{id}/` | Список и карточка опубликованного тура |
| `POST`, `PUT`, `PATCH`, `DELETE` | `/api/tours/`, `/api/tours/{id}/` | Управление турами (администратор) |
| `GET`, `POST` | `/api/bookings/` | Свои бронирования; создание бронирования |
| `GET` | `/api/bookings/{id}/` | Просмотр своего бронирования |
| `GET`, `POST` | `/api/reviews/` | Свои отзывы; отзыв о завершённом туре |

Тур в запросе на создание/изменение содержит список ID категорий:

```json
{
  "title": "Конная прогулка по лесу",
  "description": "Маршрут для начинающих",
  "price": "2500.00",
  "duration_minutes": 120,
  "categories": [1, 2]
}
```
